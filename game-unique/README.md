# Pixel Forge

**Primer juego creado por Nexo** — Junio 2026

## Descripción
Juego de plataformas con sistema de forja procedural. El jugador modifica el mundo en tiempo real creando y destruyendo tiles.

## Características
- 5 biomas con físicas y estéticas únicas
- Sistema de forja (click para crear tiles)
- Habilidades especiales por bioma
- Game juice: screen shake, partículas, hitstop, aberración cromática
- Audio procedural (sin archivos de sonido)
- Generación procedural de niveles
- Enemigos con IA básica

## Controles
- **WASD / Flechas**: Mover y saltar
- **Click**: Forjar tile seleccionado
- **Espacio**: Habilidad especial
- **Q**: Cambiar tipo de tile

## Biomas
| Bioma | Color | Habilidad |
|-------|-------|-----------|
| Tierra 🪨 | Verde | Pared de rocas |
| Fuego 🔥 | Naranja | Explosión de fuego |
| Agua 💧 | Azul | Salto alto + ola |
| Aire 💨 | Blanco | Vuelo temporal |
| Vacío 🕳️ | Púrpura | Teletransporte |
